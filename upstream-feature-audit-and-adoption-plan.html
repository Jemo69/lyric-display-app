Strategic Executive Summary: The Tale of Two Forks

Why These Two Forks Diverged & Why This Audit Matters:

When Jemo69 forked from PeterAlaks in February 2026, development split into two complementary paths:

  • Local Fork (Jemo69/master): Heavily specialized for Church Liturgy & Scriptural Ministry — adding a complete, high-performance Bible scripture presentation engine (Beblia, OpenSong, OSIS, Zefania), translations switch-in-place, RCCG TPHB song library, Vim navigation, and mobile controller remote endpoints.
  • Upstream (PeterAlaks/master): Focused extensively on Live Production Tooling & Reliability — adding the OBS Studio headless dock, service timer scheduler (.ldsch), EasyWorship database migration, MilkDrop/Butterchurn audio visualizers, hardware MIDI/OSC, atomic file saving, and pre-service health diagnostics.

The Opportunity: By cherry-picking upstream's live production, scheduling, and import features while rigorously safeguarding local Bible, RCCG, and mobile remote capabilities, this app becomes the single most capable open-source church presentation platform available.

Step-by-Step Phased Adoption Roadmap

Recommended execution sequence to avoid merge regressions
1

Phase 1: Zero-Conflict Independent Modules & Importers

Adopt modules that have zero dependencies on existing UI state or Bible code.

• EasyWorship & Document Importers: Copy main/ipc/easyworship.js, main/presentation.js, PresentationImportModal.jsx, install mammoth and paradox-reader.
• Persistent Storage Abstraction: Drop in persistentStorage.js and batched logging utilities.
• Atomic File Saving: Adopt atomicFileSave.js for safe song saving.
2

Phase 2: Live Safety, Health Checks & Output Presence

Harden live service reliability without disrupting presentation screens.

• Connected Outputs Strip: Integrate presence tracking into the top/bottom bar.
• Pre-Service Health Check: Mount PreServiceHealthModal.jsx and audit script.
• Preview Lines: Add the single-click preview / double-click project safety toggle.
3

Phase 3: Service Timer Scheduler & File Navigator

Empower service timing and fast song selection.

• Service Schedule Wizard: Port ScheduleCreatorWizard.jsx, ScheduleStartReconciliationWizard.jsx, and timerScheduler.js.
• File Navigator Modal: Port FileNavigatorModal.jsx and directory indexing IPC.
4

Phase 4: OBS Headless Dock, Multiview & Clean Routing

Streamline OBS broadcasting while safeguarding custom Bible routes.

• OBS Dock: Add obs-dock.html, pairing auth, and OBS WebSocket integration.
• Clean Router Migration: Migrate to /output, /stage, /time, /preview, and mount /bible, /output1, /output2 alongside them.
• Preview Multiview: Port Preview.jsx with support for active Bible slides.
5

Phase 5: Butterchurn Motion Backgrounds & External Controls

Add visual motion flair and hardware console triggers.

• Butterchurn Visualizers: Install butterchurn, wire 26 ambient presets into output pages with dimming control.
• MIDI & OSC Protocols: Add hardware pedal / sound console automation.
