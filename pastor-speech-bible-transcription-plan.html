Pastor Speech Transcription & Live Bible Verse Suggestions

A zero-bloat, decoupled companion service and direct-cloud hybrid architecture for LyricDisplay 6.9.0. Listens to the pastor's live sermon audio, extracts spoken scripture citations and keyphrases, benchmarks candidate models on real hardware, and presents ranked, one-tap Bible projection cards directly in the UI—without packaging gigabytes of ML weights or dependencies into the desktop installer.

Core Architectural Verdict — v2.0.0 Synthesis

1. Cloud is Zero-Install: Cloud STT (Groq / Deepgram / OpenAI) executes via the app's existing server/ proxy and secretManager.js. Choosing Cloud requires zero plugin installs, zero daemon downloads, and zero local ML dependencies.

2. Local Engine is Completely Decoupled: Local inference runs in an optional external sidecar daemon (faster-whisper via uv or standalone binary). The core Electron app stays 100% lean with zero new root dependencies.

3. Empirical Hardware Benchmarking: The in-app model selector tests candidate models on the operator's actual machine against a 30s audio sample, measuring Real-Time Factor (RTF), Word Error Rate (WER), GPU utilization, and guarding against silent CPU fallback.

4. Safety First: Machine transcripts never go directly to congregation screens. Suggestions populate an operator dock with one-tap Send Live (with twoStepFiringEnabled safety), Stage Preview, and Dismiss.

00 / Revision 2.0.0 Upgrades (Comparative Synthesis) CHANGELOG

Key enhancements synthesized from the cross-plan architectural review:

1. Direct Cloud Path (Zero Engine Required)

Removed the requirement for the companion daemon to mediate cloud calls. Cloud audio routes directly through server/speechCloudBridge.js using existing keytar secrets. Switching to Cloud is an instant settings toggle.

2. Electron & macOS Permission Fixes

Phase 1 incorporates setPermissionRequestHandler in main.js (scoped strictly to the Control Panel window) and NSMicrophoneUsageDescription in package.json, preventing native macOS crashes.

3. Local Model Benchmark Harness

Added the in-app benchmark runner to Phase 3. Measures real RTF, WER (Levenshtein), and thermal decay on the church PC rather than guessing from static catalog numbers.

4. Mechanical Zero-Bloat Invariants

Codified six automated CI tests that verify no weights or engine binaries ever contaminate the installer or root package.json.

03 / The Six Zero-Bloat Invariants TESTED INVARIANTS

Automated test suite (tests/speechOptInInvariants.test.js) fails CI if any invariant is violated:

1. Zero Bytes in Installer

package.json builder configs assert no speech-engine/ or model weights are ever bundled into production ASAR.

2. Zero New Root Dependencies

Snapshot test of root dependencies blocks PyTorch, ONNX, and heavy ML packages from being added.

3. Weights Gitignored

.gitignore rejects *.bin, *.onnx, *.pt, and CI asserts no tracked file exceeds 20MB.

4. Cold & Off by Default

With speech.enabled = false, no processes spawn, no permissions are queried, and zero network calls are made.

5. Loopback Security

Local companion binds strictly to 127.0.0.1 with ephemeral port and token authorization, blocking cross-tab hijacking.

6. True One-Click Uninstall

Settings action completely purges model weights in userData/speech-models/ and reports freed disk space.

05 / Implementation Phases PHASES
01

Platform Audio Ingest & Permission Hardening

Establish native OS permissions and Web Audio API capture pipeline.

  • Update main.js with setPermissionRequestHandler: permit media only if webContents.id === controlWindow.webContents.id; reject all output and stage projector windows.
  • Add NSMicrophoneUsageDescription to package.json's macOS build configuration.
  • Create AudioWorklet in the renderer capturing 16 kHz mono Int16 PCM in 100ms chunks with RMS audio level metering for UI waveform display.
  • Write tests/speechOptInInvariants.test.js to mechanically enforce the 6 zero-bloat invariants.
02

Direct Cloud Streaming Pipeline (Zero-Install Path)

Build the zero-install Cloud STT path through the existing backend.

  • Implement server/speechCloudBridge.js connecting directly to Deepgram Nova-3 (WebSocket) and Groq Whisper (REST streaming).
  • Leverage existing secretManager.js to store and retrieve provider API keys securely without client-side exposure.
  • Implement streaming Socket.IO partial/final transcript emission back to the renderer.
  • Verify sub-300ms transcription latency over Cloud streaming with church sermon audio.
03

Decoupled Local Companion Daemon & Benchmark Runner

Build the optional local speech engine and hardware benchmarking suite.

  • Implement companion/lyric_speech_daemon.py using faster-whisper (CTranslate2) and Silero VAD on an ephemeral loopback port.
  • Implement ephemeral security token authentication (x-ld-speech-token) and Origin validation.
  • Build src/utils/benchmarkHarness.js: runs a bundled 30s reference sermon clip across installed models to measure real RTF, WER (Levenshtein), and detect silent CPU fallback.
  • Provide one-command launch via uv run companion/lyric_speech_daemon.py or self-contained binary.
04

Scripture Reference & Semantic Verse Parsing Engine

Build the high-precision scripture extractor in src/utils/scriptureDetector.js.

  • Deterministic grammar parser handling full book names, abbreviations, and spoken numbers ("Romans chapter eight verse twenty-eight" → Romans 8:28).
  • Phonetic typo normalizer handling speech recognition oddities ("Revelations" → Revelation).
  • Semantic keyphrase search matching recited verses against the local shared/bible search index.
  • Confidence scoring (0.0 to 1.0) with debounce filtering to prevent repeated suggestions.
05

Native Operator UI & Live Bible Suggestions Dock

Deliver the operator surfaces in UserPreferencesModal.jsx and BibleControlPanel.jsx.

  • Preferences Modal: Add "Speech & AI" tab with Engine Switcher (Local vs Cloud), Model Catalog Table with benchmark results, and Download/Purge controls.
  • Live Suggestions Dock: Mount in BibleControlPanel.jsx with audio VU bar, rolling transcript snippet, and candidate verse cards.
  • One-Tap Actions: [ Send Live ] (projects verse immediately, honoring twoStepFiringEnabled), [ Stage ] (loads into preview board), and [ Dismiss ].
  • Global Shortcuts: Alt+V sends top suggestion live; Alt+X dismisses.
