Bible Translation — Switch in Place

A settings toggle that keeps the current verse on-screen when the operator changes Bible translation. No re-fielding.

Goal

Add a settings toggle named "Switch in place". When it is On, changing the active Bible translation in the Bible panel re-fetches the currently displayed reference (book / chapter / verse) from the newly selected translation and updates the on-screen verse in place — the user does not have to select the verse again.

When it is Off (the default), today's behavior is unchanged: switching translation clears the selection and the operator re-fields the reference.

If the new translation does not contain the current reference, keep the previous translation active, warn with a toast, and leave the displayed verse untouched.

Vocabulary

  • Switch in place — the toggle name (user's wording). Store key: settings.switchInPlace.
  • Translation — an imported Bible file/version in the library (bibleMetadata / bibles).
  • Reference — the selection state: activeReference (book + chapters) plus selectedVerses (verse numbers).
  • Re-field — today's flow: after a translation change the operator must browse/select the verse again.

Behavior spec

Switch in place
Re-fetch the current verse from the newly selected translation.
ScenarioToggle OffToggle On
Change translation while a verse is displayed Selection cleared. Operator re-fields the reference. Reference preserved. Same verse text fetched from the new translation and re-sent to the display in place (version label updates to the new translation).
New translation lacks book / chapter / verse N/A (selection already cleared). Warning toast: "John 3:16 not found in New International Version". Translation stays on the previous one. Display untouched.
No verse currently selected Switch translation. Switch translation normally (nothing to preserve).
Long verse / multi-slide reference N/A Slides are rebuilt from the new translation text using the existing getBibleSlides logic; slide index resets to 0.

Phases

Shared pure resolver

In shared/bible/index.js add a pure helper:

  • getBibleVerseText(bible, reference, selectedVerses) → string — extracts book/chapter/verse text for a given bible (mirrors the lookup already inside BibleStore.getVerseText).
  • Refactor BibleStore.getVerseText() (BibleStore.js:142) to delegate to it, so the store, the panel validation, and tests share one code path.
2
Store: setting + preserve reference
  1. Add switchInPlace: false to the settings default object (BibleStore.js:20-26). Persistence is automatic via partialize.
  2. Modify setActiveBible(id) (BibleStore.js:61): when settings.switchInPlace is true and activeReference exists, keep activeReference and selectedVerses instead of resetting them.
  3. Keep the existing IndexedDB load-on-demand path unchanged (still awaited before the switch lands).
3
Panel: switch handler + in-place re-send
  1. Replace the raw onChange on the translation <select> (BibleControlPanel.jsx:312) with handleBibleChange(newId).
  2. handleBibleChange:
    • No-op when newId === activeBibleId.
    • If switchInPlace is on and a reference is active: await setActiveBible(newId) (reference preserved by the store), then validate the reference resolves in the new bible via getBibleVerseText(newBible, activeReference, selectedVerses).
    • Missing reference → warning toast "John 3:16 not found in New International Version" and revert await setActiveBible(prevId) so the select returns to the original translation.
    • Resolved → build slides with existing getBibleSlides, reset slide index to 0, and call onSelectVerse (the same payload shape as sendBibleSlideToDisplay) so handleBibleVerseSelect updates the display and the translation label in place.
    • Otherwise (toggle off / no selection): setActiveBible(newId) — existing behavior.
4

  1. Add BookOpen to the lucide import (UserPreferencesModal.jsx:5).
  2. Add a sidebar entry to SIDEBAR_SECTIONS: { id: 'bible', label: 'Bible', icon: BookOpen, desc: 'Verses & translations' }.
  3. Add a BibleSection component and a case 'bible' in renderSection().
  4. Render a "Switch in place" row bound to useBibleStore → settings.switchInPlace, persisted via updateSettings({ switchInPlace: !current }). Description: "Re-fetch the current verse from the newly selected translation."
5
Tests + verification
  • Extend src/utils/__tests__/bibleReference.test.js: unit-test getBibleVerseText for present / missing book / missing chapter / missing verse.
  • Add a store test (src/context/__tests__/bibleStore.test.js) asserting setActiveBible preserves the reference when settings.switchInPlace is true and resets when false.

Risks & notes

  • Flash on missing reference: the select may briefly show the new translation before reverting. Acceptable; the toast explains it.
  • Canon differences (e.g. Psalm numbering, deuterocanon): handled by the missing-reference path, not guessed.
  • Search-all results that switch translation (handleSearchResultClick) set a fresh reference anyway — unaffected by the toggle.
  • History: no new history entry on a switch; history continues to capture operator-initiated selections.
  • Setting lives in the existing persisted settings object — no migration needed.
