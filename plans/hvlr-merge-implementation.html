02 · Work order

STEP 0

Re-base onto upstream v6.8.1

Checkout upstream/master as the new base. The two histories share no merge-base, so this is a port, not a merge:

git checkout upstream/master -b merge-base-6.8.1
# replay local-only features as patches (Bible, RCCG, splitter, lite controller,
# custom-output persistence, latency fixes) — see companion audit plan

Then execute the tracks below in order A → B → C → D → E. Each track is independently testable and revertable — do not combine tracks into one giant change.
