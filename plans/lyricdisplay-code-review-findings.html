Findings

HighDisconnect cleanup throws before completing

server/events.js:1045 calls outputInstances.entries(), but outputInstances is a plain object containing Maps, not a Map itself.

Impact: Every authenticated socket disconnect throws before the new sweep runs. Custom output metrics remain uncleared, and later disconnect work in that handler is skipped.
Fix: Replace it with Object.entries(outputInstances).

HighShared search-all flag races across Bible components

BibleStore.js:9 stores searchAllActive as a module-global flag. BibleBrowser.jsx:76, BibleSearchModal.jsx:66, and BibleControlPanel.jsx:80 independently overwrite it.

Impact: One component can turn the flag off while another component is actively searching all Bibles. That can evict loaded Bibles and refresh the worker with only the active Bible. If a component unmounts while enabled, the flag can also stay true and block future eviction.
Fix: Track active search-all owners with reference counting, or move the state into a store action with explicit mount/unmount ownership.

MediumBible parse cache retains every historical file version

main/ipc.js:1154-1169 keys bibleParsedCache by path, modification time, and size.

Impact: Each edit that changes mtime or size adds a new parsed Bible while the old entry remains in the Map. Repeated edits or imports grow main-process memory indefinitely, undermining the memory fix.
Fix: Key by file path and replace the entry when metadata changes, or prune stale entries after each load.

LowFont selection can fail silently

FontSelect.jsx:285 awaits ensureFontLoaded() without a rejection handler before calling onChange().

Impact: If a WOFF2 asset fails to load, the selection callback never runs and the menu does not close. The operator receives no feedback and the previous font remains active.
Fix: Catch loading failures, log them, and still apply the font with the browser fallback, or show a small error state.
