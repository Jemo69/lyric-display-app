Plan · Supersedes PR #21 + PR #22

Super Mobile Controller

Main Goal

One Flutter controller PR that takes the best of both competing PRs. PR #21 (feat/flutter-mobile-controller, mobile/) becomes the trunk because it owns the shipping story — CI APK releases, signing config, clean mdnsAdvertiser.js module with teardown. PR #22 (t3code/6985dfb2, lyric-display-mobile/) contributes three concepts ported into #21's architecture: subnet-sweep discovery fallback, offline socket emit queue + heartbeat, and its real test suite. Both original PRs close when this lands.

Decision Record

Keep FromWhat
#21 (trunk)Feature-first layout (features/, core/, Riverpod), dedicated mDNS advertiser with SIGINT/SIGTERM unadvertise, GitHub Actions signed-APK workflow, keystore.properties release signing, verified mDNS round-trip.
#22 (ported)Parallel subnet sweep of :4000/api/health as discovery fallback, offline emit queue + heartbeat in the socket layer, dart test suites for models and network utils, maintained bonjour-service dependency, health-endpoint discovery signature.
#22 rejectedInline mDNS publisher inside index.js with no teardown (shutdown-hang risk), entire duplicate app directory, flat lib/screens layout.

Phases

1Server Dependency Fix

Swap bonjour → bonjour-service in mdnsAdvertiser.js and package.json. Delete package-lock.json. Run bun install in server/ to regenerate bun.lock. Verify advertise/unadvertise round-trip still passes.

2Health Signature

Add name: 'LyricDisplay' and mdns: '_lyricdisplay._tcp' to /api/health. This is what lets any discovery path (mDNS or sweep) confirm it found the right server and not somebody's random device on :4000. Document in API.md.

3Subnet Sweep Fallback

New subnet_sweep.dart probes the local /24 in parallel against /api/health, validating the Phase 2 signature. Wire it into discovery_controller.dart: mDNS browse and sweep run concurrently, first validated hit wins, manual IP remains the last resort. No changes to #21's UI contracts.

4Socket Resilience

In socket_service.dart: commands emitted while disconnected buffer in an ordered queue and flush on reconnect; heartbeat ping detects half-open connections faster than Socket.IO defaults. Reconnect banner shows pending count ("3 commands queued").

5Test Coverage

Port #22's model and network-utils tests onto #21's paths; add socket queue tests for Phase 4. Target: every pure function touched by Phases 3–4 has a direct unit test.

6Verify, Ship, Close

Gate: flutter analyze clean · flutter test green · flutter build apk --debug succeeds · root bun run test green · manual mDNS round-trip on real LAN. Then push super branch, open one PR cross-referencing #21 and #22, comment on both with the supersede link, merge, close both originals.
