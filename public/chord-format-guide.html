🎵 Chord Format Guide

How to write chord charts for the Lyric Display App

🔤 Letter System (Standard Chord Names)

The app uses ChordPro format. Chords are written as standard letter names wrapped in square brackets [ChordName] inline with the lyrics.

Inline Chords (ChordPro style)

Place the chord in [ ] right before the syllable it lands on. No spaces needed between ] and the word.

{title: Amazing Grace}
{artist: John Newton}
{key: G}

[Verse 1]
[G]Amazing [G7]grace how [C]sweet the [G]sound
That [G]saved a [Em]wretch like [D]me
I [G]once was [G7]lost but [C]now am [G]found
Was [Em]blind but [D]now I [G]see

[Chorus]
[G]Praise [C]God, praise [G]God
[Em]Praise the [D]Lord
[G]Praise [C]God, praise [G/D]God
[D]Praise the [G]Lord

Chords Over Lyrics

Put a chord-only line directly above the lyric line. Column position determines which word gets the chord.

G         G7      C         G
Amazing grace, how sweet the sound
G         Em      D
That saved a wretch like me
Tip: Both styles can be mixed in the same file. Inline is more reliable for column alignment across different editors.

Directives (Metadata)

{title: Song Title}
{artist: Artist Name}
{key: G}          ← required for number system
{capo: 2}
{tempo: 80}

── Section markers ──────────────────────────────
{start_of_chorus}   or  {soc}
...
{end_of_chorus}     or  {eoc}

{start_of_verse: Verse 1}  or  {sov}
...
{end_of_verse}      or  {eov}

{start_of_bridge}   or  {sob}
{start_of_intro}
{start_of_outro}

── Bracket headers (alternative to directives) ──
[Verse 1]
[Chorus]
[Bridge]
[Intro]

🔢 Number System (Nashville Numbers)

The number system is a display mode — you always write chords as letter names. The app converts them to scale degrees automatically based on the {key:} directive.

Important: You do not type numbers in your file. Set {key:} and toggle Numbers in the UI — the conversion is live.

Example – What you type vs. what displays

What you type
{title: Amazing Grace}
{key: G}

[Verse 1]
[G]Amazing [G7]grace how
[C]sweet the [G]sound
That [G]saved a
[Em]wretch like [D]me
→
Displayed in Number mode
[1]Amazing [17]grace how
[4]sweet the [1]sound
That [1]saved a
[6m]wretch like [5]me
